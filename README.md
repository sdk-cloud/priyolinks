# ঐতিহ্য — ইসলামের ইতিহাস ও সংস্কৃতি

বাংলা ভাষায় ইসলামের ইতিহাস, সভ্যতা, শিল্প, স্থাপত্য ও সংস্কৃতি পরিচিত করানোর জন্য তৈরি একটি responsive static website।

## চালু করার নিয়ম
- `index.html` ফাইলটি ব্রাউজারে খুললেই সাইট দেখা যাবে।
- GitHub Pages চালু করতে repository-এর **Settings → Pages → Build and deployment** থেকে **Deploy from a branch** নির্বাচন করুন, branch হিসেবে `main` এবং folder হিসেবে `/ (root)` দিন, তারপর Save করুন।

## বৈশিষ্ট্য
- বাংলা responsive layout
- ইতিহাস, সভ্যতা, সংস্কৃতি ও কালপঞ্জির বিভাগ
- মোবাইল নেভিগেশন ও সাধারণ বিষয়-অনুসন্ধান
- কোনো build tool বা package installation প্রয়োজন নেই

## তথ্য-সম্পাদনা
এটি একটি প্রাথমিক পরিচিতিমূলক সংস্করণ। প্রকাশের আগে প্রতিটি ঐতিহাসিক নিবন্ধ, তারিখ ও উদ্ধৃতি নির্ভরযোগ্য একাডেমিক/প্রাথমিক সূত্র দিয়ে যাচাই ও সূত্র-তালিকা যোগ করুন। ঐতিহাসিক ব্যাখ্যার ভিন্নতা থাকলে তা স্পষ্টভাবে উল্লেখ করুন।
